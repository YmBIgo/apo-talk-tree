# APO TALK TREE

営業のアポトークに切り返しや分岐を追加し、会話の流れを木構造で設計するReactウェブアプリです。

## 主な機能

- 原本トークを行単位でノードへ変換
- トークを木構造で表示・編集
- 相手の反応、断り文句、切り返しの分岐を追加
- 選択したノードの前後へ新しいノードを挿入
- ノードを削除し、後続ノードを自動的につなぎ直す
- ブラウザのローカルストレージへ自動保存
- JSONファイルのインポート／エクスポート
- PC・スマートフォン対応

## セットアップ

Node.js 18以降を用意し、次のコマンドを実行します。

```bash
npm install
npm run dev
```

ターミナルに表示されたURLをブラウザで開いてください。

## 本番ビルド

```bash
npm run build
```

生成物は `dist/` に出力されます。

## 使い方

### 原本トークから作成する

1. 画面上部の「原本トークから作成」を選択します。
2. 営業トークを貼り付けます。
3. 「ツリーを作成する」を選択します。

入力した文章は一行ごとに一つのトークノードへ変換されます。

### ノードを編集する

ツリー上のノードを選択すると、右側の編集パネルで次の項目を変更できます。

- 種類
- ラベル
- トーク内容

種類には「自分のトーク」「相手の反応」「断り文句」「切り返し」があります。

### ノードを追加する

- **前に追加**：選択したノードの直前へ新しいノードを挿入します。
- **後ろに追加**：選択したノードと既存の後続ノードの間へ新しいノードを挿入します。
- **分岐を追加**：選択したノードの子として新しい会話分岐を追加します。

先頭ノードに対して「前に追加」を行うと、新しいノードがツリーのルートになります。

### ノードを削除する

ノードカードの削除ボタン、または編集パネルの「このノードを削除」から削除できます。削除したノードの後続ノードは、削除対象の一つ前のノードへ自動的につなぎ直されます。

ルートノードは直接削除できません。

## データの保存

編集内容はブラウザのローカルストレージへ自動保存されます。上部の「保存」ボタンから明示的に保存することもできます。

保存先は使用中のブラウザ内です。別のブラウザや端末へ移動する場合はJSONエクスポートを利用してください。

## JSONのインポート／エクスポート

画面上部の「JSON」メニューから操作できます。

- **エクスポート**：現在のツリーをJSONファイルとしてダウンロードします。
- **インポート**：このアプリから書き出したJSONファイルを読み込みます。

基本的なデータ形式は次のとおりです。

```json
{
  "version": 1,
  "title": "法人向けサービス｜初回アポ獲得",
  "updatedAt": "2026-10-27T00:00:00.000Z",
  "root": {
    "id": "n1",
    "type": "talk",
    "label": "導入",
    "text": "お世話になっております。",
    "children": [
      {
        "id": "n2",
        "type": "reaction",
        "label": "相手の反応",
        "text": "はい、大丈夫です。",
        "children": []
      }
    ]
  }
}
```

各ノードの `children` に後続ノードや分岐を格納します。`type` には次の値を使用します。

| 値 | 意味 |
| --- | --- |
| `talk` | 自分のトーク |
| `reaction` | 相手の反応 |
| `objection` | 断り文句 |
| `reply` | 切り返し |
